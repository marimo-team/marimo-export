# Guide

Start with the live market dashboard, then follow the workflow for your
notebook, consumer, agent task, frontend, or deployment.

| Task                                                      | Guide                                                  |
| --------------------------------------------------------- | ------------------------------------------------------ |
| Reach one complete producer-to-browser result             | [Run the market dashboard](getting-started.md)         |
| Select the notebook states and outputs to include         | [Choose states and results](choose-states.md)          |
| Create an export from a file or live session              | [Build or capture](build-and-capture.md)               |
| Open the export from Python, a browser, or another client | [Consume an export](consume-an-export.md)              |
| Ground an answer or generated application in export data  | [Use with agents](agents-and-automation.md)            |
| Build a purpose-specific frontend outside Python          | [Build a browser application](browser-applications.md) |
| Verify files and configure the static host                | [Deploy an export](deploy.md)                          |

Read [How notebook exports work](../overview.md) for the notebook, ExportSpec,
notebook export, and consumer model. Use the [Reference](../reference/) for
exact authored, durable, CLI, and API contracts.
