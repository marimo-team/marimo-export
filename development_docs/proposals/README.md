# Design records

Design records distinguish proposed upstream capabilities from implemented
consumer integrations. Each record links to the current owner of its contracts.

| Record                                                          | Status      | Owner                           |
| --------------------------------------------------------------- | ----------- | ------------------------------- |
| [marimo upstream capabilities](marimo-upstream-capabilities.md) | Proposed    | marimo and marimo-export        |
| [marimo-studio integration](studio-prepared-runtime.md)         | Implemented | marimo-studio and marimo-export |

Proposed APIs remain design targets until their acceptance conditions pass.
Implemented integrations use the canonical architecture maps for current
ownership and the validation guide for candidate-release acceptance.
