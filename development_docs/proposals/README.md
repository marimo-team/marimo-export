# Proposals

Proposals describe unimplemented or partially implemented designs. They are not
current architecture or validation requirements.

| Proposal                                                        | Status   | Owner                           |
| --------------------------------------------------------------- | -------- | ------------------------------- |
| [marimo upstream capabilities](marimo-upstream-capabilities.md) | Proposed | marimo and marimo-export        |
| [marimo-studio prepared runtime](studio-prepared-runtime.md)    | Proposed | marimo-studio and marimo-export |

A proposal records its date, inspected revisions, owner repositories, and
acceptance conditions. Move it into current architecture only after those
conditions pass in the owning repositories.
