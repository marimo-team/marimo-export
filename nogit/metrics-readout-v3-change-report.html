Changes

Metrics Readout V3

nogit/use-cases/metrics-readout-v3/run.py is the single entrypoint. It builds the spec, captures from the running notebook on port 8787, reads the bundle through open_export, and writes the report outputs.

Typed Metrics Artifact

metrics_exporters.py exports one JSON artifact with schema metrics.readout.v1. Presentation policy stays inside the use case, while the bundle keeps content-addressed blobs and manifest metadata.

Transport Fixes

Python and TypeScript clients now clear stale moexport modules before scratchpad imports. Python transport also serializes custom formats as explicit list entries so the target kernel parses the same public contract.

Hash Provenance Redaction

Hash-only bundles keep invocation traces without source previews, graph refs, execution output previews, or local notebook paths. The v3 metrics artifact keeps notebook name and hash only.

Example Contract Cleanup

The self-contained Markdown example now emits the current explicit custom-format spec shape. The README now points readers to open_export from moexport.query.
