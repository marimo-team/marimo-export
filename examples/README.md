# Examples

The examples progress from a deterministic notebook export to a complete browser
application.

- [Quickstart](quickstart) builds two states with an inline JSON summary and
  a rendered report. Start here to read an exported state from Python or switch
  between both states in the browser application.
- [Market dashboard with vanilla Vite](vite-vanilla) prepares five states and
  five outputs from a [Yahoo Finance](https://finance.yahoo.com/) notebook, then presents them in a
  static TypeScript application. Preparation requires network access.

Use the [getting-started guide](../docs/guide/getting-started.md) for the complete
quickstart commands and expected Python result.
